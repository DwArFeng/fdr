# Version Blacklist - 版本黑名单

## 说明

本项目的版本黑名单，列出了本项目的版本黑名单，请注意避免使用这些版本。

列入黑名单的版本，可能是因为以下原因：

- 该版本存在严重的 Bug，可能会导致核心功能无法正常使用。
- 该版本存在严重的 Bug，可能会导致数据丢失、数据错误等严重后果。

## 设计目的

该黑名单旨在帮助开发人员快速识别各版本中已知的问题点，明确受影响的模块与典型触发场景，从而做出基于事实的用/避决策与迁移安排，
而不是简单地“一刀切”禁用某一版本。

## 如何使用

黑名单不是绝对禁用清单。遇到被列入黑名单的版本时，应当基于“问题原因—是否命中—影响面”的原则进行研判：

- 是否直接或间接使用了被提及的模块/类。
- 业务中是否存在与“原因”描述相符的顺序敏感或易触发场景。
- 是否已出现与问题相符的日志告警、数据核对失败或线上异常案例。

若未使用黑名单中提及的问题代码部分，或经过验证不命中触发条件，则仍然可以继续使用该版本；若命中或存在较大不确定性，
建议参考对应编号“详细原因”章节末尾的迁移建议执行升级或规避方案，并充分做回归与灰度验证。

请注意：迁移建议仅针对对应编号的问题，所推荐版本可能仍存在其他风险。请继续核查该推荐版本是否仍在黑名单中；
若仍在黑名单中，请持续研判并迭代升级，直至风险可接受或升级至未被列入黑名单的版本。

## 详细原因

### BLACKLIST-20260712.1

原因：`BooleanTriggerRegistry.BooleanTrigger` 中布尔值判断条件反向，等于配置值时返回未触发，不等于配置值时继续进入触发分支。
该问题会导致 `boolean_trigger` 的实际触发结果与配置的期望布尔值相反，进而使依赖该触发器的数据处理、报警、联动或后续流程产生错误行为。

- 受影响模块/类：
  - `com.dwarfeng.fdr.impl.handler.trigger.BooleanTriggerRegistry`
  - `com.dwarfeng.fdr.impl.handler.trigger.BooleanTriggerRegistry.BooleanTrigger`
- 典型触发条件：
  - 使用预设触发器类型 `boolean_trigger`；
  - 触发器参数 `value` 配置为期望匹配的布尔值；
  - 待测试数据值为 `Boolean` 类型，并通过该触发器执行判定。
- 典型症状：
  - 数据值等于配置值时没有触发；
  - 数据值不等于配置值时反而触发；
  - 依赖布尔触发器的数据处理、报警、联动或后续流程表现为反向行为。
- 影响范围：
  - 直接或间接使用 `boolean_trigger` 的触发判定路径。
  - 未使用该触发器类型，或输入值不是 `Boolean` 类型的场景通常不命中此问题。

迁移建议：升级至 4.0.2.a 及以上版本。

### BLACKLIST-LEGACY-2.1.0.a

详细版本号: Release_2.1.0_20231006_build_A。

原因：存在严重 bug，导致记录启动方法被调用后，记录功能无法正常启动。

- 调用记录启动方法后，记录功能无法正常启动。
- 受影响功能包括依赖记录启动流程的数据记录场景。

迁移建议：升级至 2.1.2.a 及以上版本。

### BLACKLIST-LEGACY-2.1.1.a

详细版本号: Release_2.1.1_20231104_build_A。

原因：存在严重 bug，导致 influxdb 桥接器中部分类与变量命名不规范的问题。

- influxdb 桥接器中部分类与变量命名不规范。
- 受影响功能包括依赖 influxdb 桥接器的数据桥接场景。

迁移建议：升级至 2.1.2.a 及以上版本。

## 注意事项

- 黑名单用于风险提示，并非强制禁用。是否升级或规避，应以是否命中“详细原因”所述的模块与场景为依据。
- 建议遵循生产变更流程：评估 -> 测试 -> 灰度 -> 观测 -> 全量，过程中启用充分的日志与指标监控。
- 如发现新问题或修复版本，请同步更新本黑名单与变更记录，保持信息一致性。
